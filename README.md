Entry for the make.fun bounty "The Internet in One Word": a small
Python program that writes a single word describing the whole
internet to `/output/entry.txt`.

Run it with:

```sh
python3 main.py
```

The program uses only the Python standard library, needs no
network, and writes identical bytes on every run. The word it
writes was picked from a shortlist weighed against the bounty
judge's criteria (single word, funny by itself, true about the
internet as a whole, surprising, and landing in one beat); the
shortlist and the reasoning live in the docstring of `main.py`.
